# Shared review artifacts

Put only final, reasonably sized, team-reviewed artifacts here: concise result
tables, report-ready figures, and exports that peers need to review in Git.
Keep raw data, caches, model checkpoints, logs, and intermediate outputs in the
ignored experiment directories (for example `results/session_benchmark/`).

For each contributed artifact, add a short note or update the relevant document
with its generating command, protocol, input data manifest/checksum, split,
metric definitions, uncertainty, and limitations. Prefer source formats when
practical (CSV, SVG, and Markdown alongside final PNG/PDF exports). Do not add
private or third-party material unless its sharing terms permit it.
