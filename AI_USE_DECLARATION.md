# AI Use Declaration

**CP4285-2, Modern Recommendation Systems — Clew (group g02)**
Nguyen Dinh Nam · R Arulkumaran · Ho Chi Thanh

This project used an AI coding assistant (Claude Code, Anthropic) during
development. This declaration states how it was used, so the work it
contributed to can be assessed accordingly.

## How it was used

- **Implementation**: writing and refactoring Python modules under
  `src/session_rerank/`, `main.py`, test files, and analysis/report-generation
  scripts, from specifications and decisions set by the team.
- **Debugging and environment work**: diagnosing failing tests, fixing
  cross-platform issues (e.g. the LightGBM/pandas import-order crash on
  Windows noted in `src/session_rerank/__init__.py`), and setting up the GPU
  cluster batch scripts in `scripts/cluster/`.
- **Documentation drafting**: drafting and editing `REPORT.md`, `ETHICS.md`,
  `HANDOFF.md`, `EXPERIMENT_LOG.md` and this repository's `README.md` from the
  team's results, decisions and source material, with the team reviewing and
  editing the content.
- **Repository curation**: selecting and committing the final, reproducible
  subset of this repository's code and results to the `main` branch, as
  directed by the team, separating it from exploratory and superseded work
  kept on other branches.

## What was not AI-generated

The research question, experimental design, choice of models and metrics,
the decision rules (e.g. the 5% relevance-loss budget for the diversity
step), interpretation of the results, and the conclusions reported in
`REPORT.md` are the team's own. Final-test numbers were produced by running
the team's code against the dataset, not generated by the assistant.

## Oversight

All AI-assisted code and text was reviewed, tested and, where necessary,
corrected by the team before being treated as part of the submission. The
team takes full responsibility for the content of this repository.
